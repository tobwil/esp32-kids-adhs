# Bildbeschreibungen für die Pferdekarten

Für einen Bildgenerator deiner Wahl. Jede Beschreibung verlangt ein ganzes Pferd von der Seite im Querformat 5:3, ohne Text.
Speichere die Bilder als `<Nr>.png` oder `<Nr>-name.jpg` in einen Ordner und übernimm sie mit

```bash
tools/.venv/bin/python tools/horses.py import ~/Pferdebilder
tools/.venv/bin/python tools/horses.py review
tools/.venv/bin/python tools/horses.py upload
```

Nichts wird abgeschnitten: Passt das Seitenverhältnis nicht, füllt der Import den Rand mit einer unscharfen Fassung desselben Bildes.
